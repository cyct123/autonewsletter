AI Prompts Page — Which Layout?

All three store prompts in SystemConfig and include Reset to Default. The difference is how you navigate and save.

Admin › AI Prompts
SUMMARIZATION PROMPT
你是中文资讯编辑，按以下标准生成中文内容...
TRANSLATION PROMPT
将以下标题精准翻译为中文标题...

A — Single page, Save All

Both prompts on one page, one submit saves everything. Reset per prompt.

Pros

  • Simple, one action
  • Easy to compare prompts side by side

Cons

  • Must re-save both even when changing one

⭐ Recommended

B — Single page, Save each

Both prompts on one page, each with its own Save + Reset. Saves independently.

Pros

  • Surgical edits — save only what changed

Cons

  • Two forms, more complex implementation
  • Flash messages need per-form identity

C — Tabbed page

One tab per prompt. Larger textarea, focused editing. Switch tabs to change prompt.

Pros

  • More vertical space per prompt

Cons

  • Can't see both at once
  • Needs JS for tab switching
