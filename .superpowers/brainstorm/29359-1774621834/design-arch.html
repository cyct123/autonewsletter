管理后台架构设计

基于 SQLAdmin + FastAPI，挂载到 /admin 路径

整体结构

目录变更
app/
  admin/
    __init__.py
    views/
      source.py     ← 内容源管理
      subscriber.py  ← 订阅者管理
      content.py    ← 内容查看
      send_log.py   ← 发送日志
      app_config.py  ← AI/定时任务配置
  models/
    app_config.py  ← 新增：配置表模型
  main.py        ← 挂载 admin
requirements.txt  ← 新增 sqladmin
alembic/versions/  ← 新增 app_config 迁移

访问方式

URL 路由
GET /admin            ← 管理后台首页
GET /admin/source      ← 内容源列表
GET /admin/subscriber  ← 订阅者列表
GET /admin/content     ← 内容列表
GET /admin/sendlog     ← 发送日志
GET /admin/appconfig   ← 系统配置
POST /trigger           ← 手动触发（现有）
